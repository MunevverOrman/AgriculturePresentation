🌾 Tarım Web Sitesi — N Katmanlı Mimari Projesi

C# | ASP.NET Core MVC | N Katmanlı Mimari | Identity | SQL Server

Bu proje, Udemy’de Murat Yücedağ eğitmenliğinde yayınlanan
“C# ile OOP Temelleri: Adım Adım Katmanlı Mimari” kursu kapsamında geliştirilmiştir.
Amaç, OOP mantığını gerçek bir projede uygulayarak katmanlı mimarinin nasıl çalıştığını gözlemlemek ve yönetilebilir bir web sitesi geliştirmektir.

🎯 Projenin Amacı
OOP yapısını uygulayarak profesyonel bir proje geliştirmek

N katmanlı mimariyi pratikte öğrenmek

SQL veri tabanı, prosedür ve tetikleyicilerle çalışma deneyimi kazanmak

Admin paneli ile tüm site içeriğini yönetilebilir hale getirmek

🌟 Proje Özeti
Bu çalışma, ziyaretçilere ürünler, hizmetler, haberler ve duyurular sağlayan bir tarım tanıtım web sitesidir.

👨‍💻 Admin Paneli Özellikleri
📊 Dashboard (İstatistikler & grafikler)
🧩 Hizmet Yönetimi
👥 Takım Arkadaşları Yönetimi
📰 Haber ve Duyuru Yönetimi
✉️ Gelen Mesajlar
📈 Grafikler
📝 Raporlama Modülü

🔐 Kimlik Doğrulama
Login (Giriş Yap)
Register (Kayıt Ol)
Kullanıcı doğrulama
Roller & yetkilendirme
Sistem tamamen ASP.NET Core Identity ile geliştirilmiştir.

🏛 Kullanılan Mimari Yapı
Proje, N Katmanlı Mimari (N-Layer Architecture) yapısını temel alır:
EntityLayer → Varlık sınıfları
DataAccessLayer → EF Core, Repository, SQL operasyonları
BusinessLayer → İş kuralları, FluentValidation
PresentationLayer → MVC arayüzü, Controller & ViewComponent yapısı

Bu mimari sayesinde proje:
✔ Modüler
✔ Sürdürülebilir
✔ Test edilebilir
✔ Genişletilebilir
hale gelmiştir.

🛠 Kullanılan Teknolojiler
C# .NET Core MVC
Entity Framework Core
ASP.NET Core Identity
FluentValidation
MS SQL Server
Chart.js
Bootstrap 4/5
Repository Pattern
